# kyc-screening-simulator
KYC Screening Simulator

A simple Python project that simulates a basic KYC screening process.

What it does

The script checks fictional client data against four simple rules:

Transaction amount above a defined limit
High-risk country
Recently opened account
Transaction above 3x monthly salary

If a rule is triggered, the client is flagged for attention.

Example
⚠️ John Doe - ATTENTION:
   - Transaction above limit
   - High-risk country
   - Account too recent
   - Transaction above 3x monthly salary
